## O que é?

O **Estudie** ajuda você a manter o ritmo de estudo ou trabalho com perfis estilo **Pomodoro**, anel de progresso, tarefa opcional na tela, ruído **rosa** e trilhas **MP3 locais**.

| | |
|:---:|:---:|
| ⏱️ **Perfis** | Pomodoro, deep work, manutenção e blocos curtos — minutos editáveis |
| 🎯 **Timer** | Foco / pausa, +5 min, atalho **Espaço** para play/pause |
| 🔊 **Som** | Ruído rosa (Web Audio) ou música da pasta `audio/` |
| 🔒 **Privacidade** | Preferências e tarefa só no `localStorage` |
| 🛡️ **Segurança** | CSP e políticas no `index.html` + `_headers` para Netlify |

---

## Destaques

- Vários ritmos de trabalho com minutos personalizáveis  
- Vibração ao terminar o bloco (quando o dispositivo permite)  
- Volume compartilhado entre rosa e trilhas MP3  
- 100% estático — abra e use

## Rodar localmente

```bash
git clone https://github.com/maliraa07/Projeto_Estudie.git
cd Projeto_Estudie
```

Abra `index.html` no navegador ou use um servidor local:

```bash
python -m http.server 5500
```

## Trilhas em `audio/`

O menu usa a lista **`MUSIC_TRACKS`** em `js/app.js`. Arquivos esperados por padrão:

| Arquivo | Nome no menu |
|---------|----------------|
| `audio/calma.mp3` | Calma |
| `audio/foco.mp3` | Foco |
| `audio/leve.mp3` | Leve |
| `audio/ambiente.mp3` | Ambiente |
| `audio/estudo.mp3` | Estudo |

Consulte `audio/ATRIBUICAO.txt` para créditos de trilhas Kevin MacLeod, se aplicável.
